# nudge

Ask from the terminal, answer on your phone.

A coding agent calls nudge's `ask` tool over MCP, or runs `nudge ask --option Yes --option No "Merge the pull request?"` in its shell. Your phone shows a notification; you tap an option or type a reply; the answer goes back to the agent, and the agent carries on.

nudge is being built step by step. The plan is in [`docs/plan.md`](docs/plan.md), and the rules for working on it are in [`AGENTS.md`](AGENTS.md). [`docs/setup.md`](docs/setup.md) says how to run it on a Mac.
