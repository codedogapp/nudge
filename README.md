# nudge

Ask from the terminal, answer on your phone.

A coding agent runs `nudge ask --option Yes --option No "Merge the pull request?"`. Your phone shows a notification; you tap an option or type a reply; the answer prints in the agent's shell, and the agent carries on.

nudge is being built step by step. The plan is in [`docs/plan.md`](docs/plan.md), and the rules for working on it are in [`AGENTS.md`](AGENTS.md).
